Platforms & Connection

      
Enable platforms and follow instructions to connect auto-publishing

      


        
        

           💬 Telegram
          
        

        

          

            How to connect:

            1. Open @BotFather in Telegram

            2. Send /newbot → pick a name → get token

            3. Create a channel and add the bot as admin ("Post Messages" permission)

            4. Paste the token and channel @username below
          

          

            
            
          

        


        
        

           🎮 Discord
          
        

        

          

            How to connect:

            1. Open Discord server → Settings → Integrations → Webhooks

            2. Click New Webhook → select channel

            3. Click Copy Webhook URL → paste below
          

          
        


        
        

           🐦 Twitter / X
          
        

        

          

            How to connect:

            1. developer.x.com → Create App → OAuth 1.0a (Read and Write)

            2. Paste all 4 keys below
          

          

            
            
            
            
          

        


        
        

           💼 LinkedIn
          
        

        

          

            How to connect:

            1. linkedin.com/developers → Create App → request w_member_social

            2. Get Access Token and Person URN (urn:li:person:XXXXX)
          

          

            
            
          

        


        
        

           📘 Facebook
        

        

          

            How to connect:

            1. developers.facebook.com → Create App

            2. Get Page Access Token and Page ID
          

          

            
            
          

        


        
        

           📷 Instagram
          
        

        

          

            How to connect:

            1. Instagram → Settings → Switch to Professional (Business) account

            2. Connect Instagram to Facebook Page (Settings → Linked Accounts)

            3. Graph API Explorer → permissions: instagram_basic, instagram_content_publish

            4. GET /me/accounts → find page → GET /{page_id}?fields=instagram_business_account
          

          

            
            
          

        


        
        

           🧵 Threads
          
        

        

          

            How to connect:

            1. Same Meta Developer App as for Instagram

            2. Permissions: threads_basic, threads_content_publish

            3. Threads User ID = your Instagram/Threads user ID
